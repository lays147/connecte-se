## Priority Issues

**[P0] Cookie consent banner covers functional UI on load, on all three pages, every session.**
Why it matters: Confirmed directly in screenshots. On mapa.html mobile, the banner sits mid-page and overlaps the "Ranking por Estado" state list. On mapa.html desktop, it clips the ranking's bottom rows. On index.html mobile, it covers the Região/Tipo/Pago filter selects — the first controls a new visitor would reach for. This is the very first thing every visitor sees, and it breaks the exact UI they need.
Fix: Reserve space for the banner (padding-bottom on the page while it's mounted) or convert it to a corner-anchored toast with a max-width that never spans full content width.
Suggested command: /impeccable harden

**[P1] Two filter surfaces exceed the site's own density/cognitive-load discipline.**
Why it matters: The content page's 6 format tabs + 6 theme chips are simultaneously visible (not progressively disclosed), wrapping to 2-3 rows on mobile. The event filter bar's Tipo select has 12 real values but only 5 are styled in the accent-color taxonomy — 6 of 11 event types render as flat NEUTRAL grey, undermining DESIGN.md's own "flat colored strips as taxonomy" rule.
Fix: Consolidate event types into the 5 already-styled families (fold Congresso/Summit into existing colors, map stragglers to CORAL or an "Outro" bucket); turn content-page chips into a single select or "+N more" overflow.
Suggested command: /impeccable distill

**[P1] No persisted or shareable filter/map-selection state.**
Why it matters: Filter and map state live in memory only (appState.ts, filters.ts) with no URL sync. A user who filters to "Sul + Workshop + Gratuito" and hits back loses everything; nobody can share a link to "eventos em SP." For a discovery product whose value is connecting one person to one opportunity, this weakens the core shareability loop.
Fix: Mirror filter state and the map's selected/scope into the URL query string.
Suggested command: /impeccable harden

**[P2] A literal "placeholder" event record reaches production data.**
Why it matters: src/data/events-2026.json contains an entry with id "2026-01-placeholder", title "placeholder", type "placeholder". If unfiltered, this surfaces as a selectable Tipo option and possibly a card — a small crack in the "best-effort but real" trust claim.
Fix: Add a build/scrape-time guard rejecting any record with a literal placeholder title or type before it reaches committed JSON.
Suggested command: /impeccable audit

**[P3] No visible keyboard-focus styling on filter selects, search input, or content-page chips/tabs.**
Why it matters: DESIGN.md already self-admits this gap. Keyboard users tabbing through 12+ chip/tab buttons have no clear position indicator.
Fix: Add focus-visible:ring-2 ring-brand-400 to selects, search input, and chip/tab buttons.
Suggested command: /impeccable audit

## Persona Red Flags

**Sam (Accessibility-dependent)**: No custom focus ring anywhere in the filter/chip system (confirmed in code and self-admitted in DESIGN.md). The map's state-selection is built entirely on SVG mousemove/click handlers with no apparent keyboard equivalent — a keyboard-only user cannot select a state directly on the map (the ranking-list rows are the only fallback, and their keyboard accessibility wasn't confirmed either).

**Casey (Mobile)**: The cookie banner covers the Região/Tipo/Pago filters on first load — the exact controls Casey would reach for first, with nothing signaling "there's something under here." The header nav wraps to two rows before any content appears. The full mobile index page renders to 16,156px in one continuous scroll with no pagination on the current year's ~150 events (only "Carregar 2026" gates future years).

## Minor Observations

- Three different "grouping" UI patterns (group toggle, format tabs, theme chips) do conceptually the same job with different visual weight.
- Content-page search has no debounce — fast typing triggers a full re-render per keystroke.
- The map's hand-tuned label offsets for small states (DF, RJ, ES, AL...) is a genuine craft detail worth preserving in any future map work.
